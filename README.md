# Template Esercitazioni Python – 4ª ITT

Repository modello preconfigurato con ambiente di sviluppo minimale (senza autocompletamento né assistenti IA) per le esercitazioni e le verifiche di Informatica.

---

## 1. Creare il proprio repository dal template

1. Clicca sul pulsante verde **Use this template** in alto a destra e seleziona **Create a new repository**.
2. Assegna un nome al repository seguendo il formato richiesto (es. `es01-cognome-nome`), imposta la visibilità su **Private** e clicca su **Create repository**.

## 2. Avviare l'ambiente di lavoro (GitHub Codespaces)

1. Nella pagina del tuo nuovo repository, clicca sul pulsante verde **<> Code**.
2. Seleziona la scheda **Codespaces** e clicca su **Create codespace on main**.
3. Attendi il caricamento dell'editor (al primo avvio può richiedere circa 1–2 minuti).

## 3. Svolgere ed eseguire l'esercizio

1. Apri il file `app.py` dalla barra laterale sinistra.
2. Aggiorna i campi **Autore** e **Data** nell'intestazione in alto.
3. Scrivi il codice richiesto all'interno della funzione `main()`.
4. Per eseguire il programma, clicca sull'icona **Play (▶)** in alto a destra oppure digita nel terminale:
   ```bash
   python main.py
